# JML PowerPoint Studio

Windows와 데스크톱 PowerPoint를 사용하는 음성 발표 프로그램입니다. 현재 정식 버전은 1.0.0입니다.

공개 릴리스에는 버전과 변경 사항만 게시합니다. 설치파일은 [비공개 릴리스](https://github.com/skw1010/jml-powerpoint-studio-downloads/releases)에서 접근 권한이 있는 GitHub 계정으로 로그인해 내려받으세요. 접근 권한은 관리자에게 요청하세요.

Windows 10/11 64비트, Google Chrome, 데스크톱 PowerPoint가 필요합니다. 업데이트 알림에서 다운로드 버튼을 누르면 비공개 릴리스 페이지가 열립니다.

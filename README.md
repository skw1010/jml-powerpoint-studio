# JML PowerPoint Studio

Windows용 PowerPoint 음성 발표 프로그램의 **공개 배포 전용 저장소**입니다. 소스 코드는 이 저장소에 포함하지 않습니다.

## 다운로드

[최신 버전 설치파일](https://github.com/skw1010/jml-powerpoint-studio/releases/latest)에서 `JML-PowerPoint-Studio-버전-Setup.exe`를 다운로드하세요.

- Python을 별도로 설치할 필요가 없습니다.
- Windows 10/11 64비트, Microsoft Edge, 데스크톱 PowerPoint가 필요합니다.
- 설치 후 바탕화면의 JML PowerPoint Studio를 실행하세요.
- 현재 배포본은 코드 서명되지 않았습니다.

## 업데이트

1. 앱 시작 시 GitHub의 최신 정식 릴리스를 확인합니다.
2. 새 버전이 있으면 현재 버전·새 버전·변경 내용을 팝업으로 표시합니다.
3. ‘업데이트 다운로드’를 누르면 설치파일을 내려받고 SHA-256을 확인합니다.
4. ‘종료 후 설치’를 누르면 앱을 종료하고 설치 프로그램을 실행합니다.

인터넷 연결이 끊겨도 발표는 계속 사용할 수 있습니다. 업데이트는 동의 없이 설치하지 않습니다. ‘업데이트 확인’ 버튼으로 다시 확인할 수도 있습니다.

## 주요 기능

- PPTX 슬라이드·발표자 노트·미리보기 가져오기
- 슬라이드별 대본 편집과 프로젝트 저장
- 음성 대본 추적 및 PowerPoint 페이지 연동
- 발표자·청중 모니터 선택
- 화면 기준 인식 범위 25~200%, 기본 100%

원본 PPTX는 임시 복사본으로 실행하며, 노트 수정 반영본은 별도로 저장합니다. 음성인식은 브라우저 제공 서비스를 사용하므로 인터넷 연결과 마이크 권한이 필요할 수 있습니다.

## 배포 파일

각 릴리스에는 Windows 설치파일과 `SHA256SUMS.txt`가 포함됩니다. 정식 릴리스 태그는 `v1.1.0`처럼 `v주.부.수정` 형식입니다. 초안과 사전 릴리스는 자동 업데이트 대상에서 제외됩니다.

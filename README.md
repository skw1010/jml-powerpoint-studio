# JML PowerPoint Studio

Windows와 데스크톱 PowerPoint를 사용하는 발표 프로그램의 시험 버전 안내 저장소입니다.

공개 릴리스는 버전과 변경 사항을 제공합니다. 설치파일은 [비공개 다운로드 저장소](https://github.com/skw1010/jml-powerpoint-studio-downloads/releases)에서 GitHub에 로그인한 허용 사용자만 받을 수 있습니다. 접근 권한은 관리자에게 요청하세요.

현재 시험 버전은 0.0.1입니다. 업데이트 알림의 다운로드 버튼을 누르면 비공개 릴리스 페이지가 열립니다. 설치파일을 내려받아 직접 실행하세요.
